Política de Privacidade

Como recolhemos, utilizamos e protegemos os teus dados pessoais.

A tua privacidade é importante para nós. O Conecta Já compromete-se a proteger os teus dados pessoais e a ser transparente sobre como os utilizamos.

1. Dados que Recolhemos

Recolhemos apenas os dados necessários para o funcionamento da Plataforma:

  • Dados de registo: nome, email, número de telefone e tipo de conta
  • Dados de perfil: foto, bio profissional, localização e categorias de serviço
  • Dados de utilização: pedidos de serviço, avaliações e mensagens
  • Dados técnicos: endereço IP, tipo de dispositivo e dados de navegação

2. Como Utilizamos os teus Dados

Os teus dados são utilizados para:

  • Fornecer e melhorar os serviços da Plataforma
  • Verificar identidades e autenticar utilizadores
  • Facilitar a comunicação entre clientes e prestadores
  • Enviar notificações relevantes sobre a tua conta
  • Cumprir obrigações legais
  • Analisar e melhorar a experiência de utilização

3. Partilha de Dados

Não vendemos os teus dados a terceiros. Podemos partilhar informações com:

  • Outros utilizadores: O perfil público dos prestadores é visível a clientes
  • Prestadores de serviços técnicos: que nos ajudam a operar a Plataforma
  • Autoridades competentes: quando exigido por lei

4. Segurança dos Dados

Implementamos medidas técnicas e organizacionais para proteger os teus dados, incluindo encriptação de dados sensíveis, controlos de acesso e monitorização de segurança. No entanto, nenhum sistema é 100% seguro.

5. Cookies

Utilizamos cookies e tecnologias similares para melhorar a tua experiência. Podes gerir as preferências de cookies nas definições do teu navegador. Os cookies essenciais são necessários para o funcionamento da Plataforma.

6. Os teus Direitos

Acesso

Podes solicitar uma cópia dos teus dados pessoais.

Retificação

Podes corrigir dados incorretos ou incompletos.

Eliminação

Podes pedir a eliminação dos teus dados.

Oposição

Podes opor-te ao processamento dos teus dados.

Portabilidade

Podes obter os teus dados num formato legível.

Limitação

Podes solicitar a limitação do processamento.

Para exercer estes direitos, contacta-nos em conectaja.ao@gmail.com.

7. Retenção de Dados

Conservamos os teus dados enquanto a tua conta estiver ativa ou enquanto necessário para prestar serviços. Após o encerramento da conta, os dados são eliminados em até 90 dias, salvo obrigação legal de conservação mais prolongada.

8. Menores de Idade

A Plataforma não é destinada a menores de 18 anos. Não recolhemos intencionalmente dados de menores. Se tomarmos conhecimento da recolha de dados de menores, os mesmos serão eliminados imediatamente.

9. Alterações a esta Política

Podemos atualizar esta política periodicamente. Notificaremos os utilizadores sobre alterações significativas por email ou através da Plataforma. A data de última atualização está sempre indicada no topo deste documento.

10. Contacto

Para questões sobre privacidade, contacta-nos em conectaja.ao@gmail.com ou pelo formulário em contacto.html.
